# Addis Eats

A simple React food-ordering website.

## Features

- reusable components
- props
- jsx
- map()
- PropTypes
- Conditional rendering
- children prop
- Filtered menu
- React state with useState
- Event handling
- Controlled inputs
- Lifting state up
- Form submission handling
- Input validation


## Built With

* React
* Vite
* JavaScript
* CSS

## How to Run

```bash
npm install
npm run dev
```
Then open the local URL shown in the terminal.
